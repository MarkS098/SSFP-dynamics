
A MATLAB-based computational suite for extracting chemical exchange kinetics and transverse relaxation rates from Steady-State Free Precession (SSFP) NMR data. This package uses a Liouville-space Bloch-McConnell formalism to perform global joint fitting across multiple resonance sites.OverviewThis package is designed to analyze NMR signal attenuation as a function of repetition time ($T_R$) and off-resonance conditions. It provides a robust framework for resolving the mathematical degeneracy between chemical exchange ($k_{ex}$) and transverse relaxation ($R_2$) through global optimization and rigorous uncertainty quantification.Key FeaturesLiouville-Space Simulation: Exact numerical solution of the Bloch-McConnell equations using matrix exponential propagators.Global Joint Fitting: Simultaneous optimization of multiple peaks (e.g., Site A and Site B) using a shared parameter set and an analytical global scale factor.Global Search Strategy: Combines Latin Hypercube Sampling (LHS) with a MultiStart heuristic to identify the true global $\chi^2$ minimum.Non-Parametric Bootstrap: Rigorous uncertainty quantification using dataset-segregated residual resampling.Error Surface Mapping: Dynamic 2D topographical mapping of the objective function to visualize parameter correlations.Package StructureCore Processing Scriptsraw_data_process.m: The primary entry point for raw Bruker data. It handles directory traversal, applies FFT, frequency axis calibration (ppm), and extracts peak intensities for subsequent fitting.ssfp_exchange_jointfit.m: The main optimization engine. It loads processed data, executes the MultiStart global search, performs bootstrap error analysis, and generates diagnostic error surface plots.chem_exchange_sim.m: The physical forward model. It constructs the 10-dimensional Liouvillian matrix (relaxation, precession, and kinetics) and solves for the periodic steady state.Utility Scripts (Bruker I/O)read_ssfp_acqus.m: Parses Bruker acqus files to extract critical hardware parameters (Carrier Frequency, Transmitter Offset, Flip Angle, $T_R$).read_ssfp_procs.m: Parses Bruker procs files for processing parameters like SI and NC_proc.read_bruker_data.m: Binary reader for fid or ser files, compatible with TopSpin 3 (int32) and TopSpin 4 (double) formats.
